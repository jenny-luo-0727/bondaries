What counts as a tokenization crime?
Split atom
One atom’s SMILES text crosses token boundaries.
Detached ring closure
A ring label belongs to a different token than the preceding atom.
Context merge
A token spans both the prefix and the SMILES.
Dropped character
A SMILES character has no token owner and cannot be reconstructed.

Split atoms use their first character’s token color. Hovering shows every contributing token. Colors repeat every eight tokens.
